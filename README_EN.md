# Smart Research & Development Agent Platform

An enterprise-oriented AI Agent orchestration platform built with Java 17, Spring Boot 3, Spring AI and a DDD layered architecture.

This project is a scenario-focused extension of the TAgent execution engine for development teams. It adds a GitHub Issue analysis endpoint, while reusing Agent routing, MCP tools, Agentic RAG, Redis run snapshots and SSE streaming.

See the [Chinese README](README.md) for the complete feature list, local deployment instructions and resume-oriented project description.
